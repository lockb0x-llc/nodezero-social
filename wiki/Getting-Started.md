# Getting Started

## Prerequisites

- Node.js 18+
- pnpm 8+
- PowerShell and bash

## Install

```bash
pnpm install
```

## Run quality gates

```bash
pnpm lint
pnpm type-check
pnpm test
pnpm policy:validate-env
```

## Useful commands

- `pnpm qa:smoke`
- `pnpm deploy:stellar:testnet`
- `pnpm deploy:azure`
